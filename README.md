# homebrew-display-toggle

Homebrew tap for [display-toggle](https://github.com/Crispy1975/display-toggle) — a macOS command-line tool to toggle any display on or off by UUID.

## Install

```sh
brew tap Crispy1975/display-toggle
brew install display-toggle
```

## Usage & documentation

See the [display-toggle repository](https://github.com/Crispy1975/display-toggle) for full documentation.
